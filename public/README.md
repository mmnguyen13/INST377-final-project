# Student Club Finder

## Project Description
Student Club Finder is a full-stack web application designed to help students discover clubs and organizations around campus. Users can browse clubs, add new clubs, and explore random campus activity suggestions. The application was built using Node.js, Express, Supabase, HTML, CSS, and JavaScript.
The goal of this project is to make it easier for students to become involved on campus and find organizations that match their interests.


## Target Browsers
This application was tested and works on:

- Google Chrome (recommended)
- Safari
- Microsoft 

The application is designed for both desktop and laptop browsers and is compatible with:
- macOS
- Windows
- iOS Safari
- Android Chrome
